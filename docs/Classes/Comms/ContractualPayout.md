# In Short

Message transmitting a TimeStamp, a total payout as well as a support payout amount.

# Details

Contained information:

* `validAt`: The time the DataItem is valid at
* `totalRevenuesInEUR`: The overall payment that is paid out in EUR
* `supportInEUR`: The support payment in EUR (*Note*: This value is contained in `totalRevenuesInEUR` in EUR)
